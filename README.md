## Typing Practice Game

This is a simple browser-based typing practice game built using **HTML, CSS, and JavaScript**. When the user clicks **Start**, a random quote is displayed on the screen and the player must type it as quickly and accurately as possible. The game highlights the current word being typed, detects mistakes in real time, and measures how long the user takes to complete the quote.

I built this project as part of my hands-on learning approach to web development. I prefer learning by building small working applications, experimenting with code, debugging issues, and understanding how different parts of a system interact.

Through this project I practiced:

* DOM manipulation using JavaScript
* Event handling and user input tracking
* Basic UI feedback (highlighting correct/incorrect typing)
* Structuring a small interactive frontend application

The goal of the project was not just to recreate a typing game, but to better understand how **JavaScript interacts with the browser, updates the UI dynamically, and manages application state in real time**.
